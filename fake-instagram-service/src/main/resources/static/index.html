🔗 How to Connect InstaMngmt to the Simulator

The Fake Instagram API Simulator runs on http://localhost:8085. To switch InstaMngmt from Real Instagram to this Fake Simulator, set the following configuration in application.yml or environment variables: 

instagram:
  provider: fake
  simulator-base-url: http://localhost:8085
  graph-api-base-url: http://localhost:8085

Connecting an Account in the InstaMngmt UI:

  1. Go to the Accounts Explorer tab in this simulator dashboard.
  2. Click "Copy Token" on any generated account.
  3. In your InstaMngmt web UI, open Connect Account Modal.
  4. Paste the copied Access Token and Instagram User ID.
  5. Click Verify & Connect. The account is instantly linked with live verified followers and bio!
